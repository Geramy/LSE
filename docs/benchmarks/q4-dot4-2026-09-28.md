# Q4 DOT4 exact plane extraction

The live baseline profile's M1 Q4 kernels account for 27.8333 ms per target
step (67 target steps represented). The registered DOT4 body is unchanged
from 89ca1e6 and 85d1293; this is an inherited missed simplification. The actual unique packed weights plus BF16
scale/bias streams total 14,412,349,440 bytes per step (13.4225 GiB), implying
517.8 GB/s against that CP time. This is logical compulsory traffic, not
measured DRAM traffic; no marketing model-size estimate is used.

Each packed word's planes are exactly `(w & 0x0f0f0f0f)` and
`((w / 16) & 0x0f0f0f0f)`. The prior helper rebuilt each nibble independently.
The change uses one generic unsigned AND row in each dialect, required by
existing integer-path capability checks. FP32 arithmetic/quantization order,
weights, group sums, launches and epilogues are unchanged.

## Native gate

Both full projections passed all 22,528 output components: baseline/candidate
bit equality, independent per-chunk integer oracle with non-dyadic inputs,
finite completion, within-arm repeats, input integrity and 64-byte guards.
All 172 device dispatches had valid CP timestamps; 0 host/fallback dispatches.
The actual mapped HSA image is build/hsa/libhsa-runtime64.0.1.0.dylib,
SHA b7f8216e32fa6ab0e5b2fce87c518ce67c3fffa4c628cceece983c53e3cea90d.

was left unchanged. Candidate source and CO bytes match the offline objects.
