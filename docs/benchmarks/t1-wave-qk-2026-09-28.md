# T1 split attention: wave-cooperative QK

The T1 partial reuses the existing ShortQuery QK algorithm. Each wave computes one key with eight FP32 FMAs per lane and a
32-lane XOR reduction. The 128-key partition ABI, masks, paging, PV arithmetic,
launch geometry and merge are unchanged. The displaced serial QK loop is
removed; existing split primitives and dispatch admission remain.

## Native results

gfx1201, wave32, H=24, KVH=4, D=256, block=16. All times include partial and
merge; no compilation is inside the timed samples. Eight warmups per arm,
ABBA20, 40 measured invocations per arm. Passive CP reports a 100 MHz timestamp
clock; this is not GPU core frequency.

Both candidate CP arms beat both original arms in every case. The gain is
supported by changing the key access layout from one key per lane and serial
256-dimensional reads to contiguous dimensions across each wave. No occupancy
or dynamic bandwidth measurement is claimed.

## Correctness and resources

- Two additional ragged batch=3 / sliding=257 cases passed in F16/BF16. The short
  row has 143 keys; inactive queries contain NaNs and invalid page IDs. Tail K/V
  beyond each row length are NaN.
- Every output was checked against an independent double reference consuming
  exactly decoded stored K/V. Maximum absolute error was 2.60770321e-8 across
  the F16/BF16 cases. Maximum original/candidate difference was 7.4505806e-9. QK FP32
  reduction order intentionally changes; outputs are not claimed bit identical.
- Every partial record was checked for valid finite numerators/denominators,
  non-NaN maxima, and guard preservation. Poisoned empty replay produced exact
  (-inf,+0,+0[256]) records and +0 outputs; restored metadata passed again.
- Inputs remained byte identical. All 840 dispatches were native, with 0 host
  dispatches and 0 fallback dispatches.
- A current-canonical production subset additionally passed F32, FP8 and BF8
  at T1/live=513/capacity=8192: 18 native dispatches, zero host/fallback.
  Raw writer payload/scale bits matched the format codec, all output elements
  passed the decoded-storage double oracle (maximum error 9.61536788e-8),
  and empty retained replay, read-only inputs and 256-byte guards passed.
  These formats were checked for correctness without performance repetitions.
- Both measured F16/BF16 partials use 512 B LDS. Original partial V15/S24; candidate F16 V34/S44,
  BF16 V36/S44 (ragged edge S46). All measured F16/BF16 partial/merge code objects report known
  private allocation 0 B/work-item. Register spill counts are unknown.
- ISA contains no scratch loads/stores or dual issue math packets. F16 operands
  use v_fma_mix_f32 with FP32 accumulator selection, preserving FP32 arithmetic.
  Candidate QK loads eight contiguous dimension groups and has a lane-shuffle
  reduction; barriers remain three signal/wait pairs.
