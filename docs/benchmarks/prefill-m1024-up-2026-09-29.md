# M1024 Q4 gate/up: cooperative activation staging

## Scope

Only M1024/N17408/K5120 Q4 group64 with BF16 affine planes on gfx1201/wave32/WG256 uses the new schedule. The producer prepares four M16 fragment records. A workgroup stages their 1,152 U32 words (4,608 bytes) once in LDS, then eight column waves share them. Gate and up share a single producer for the same input node. The shape table selects LDS staging and checks the device budget. No architecture check is added to the numeric body.

The previously accepted M8 and M1024 down producer/consumer emitted sources and complete launch plans remain byte-identical. Floating-point accumulation remains FP32. Compact Q4 weights are unchanged.
